# CryptunaPriceWidget — Bybit Spot / USDT

Python 3.10+, стандартная библиотека. Крипта теперь с Bybit, CMC полностью исключён из запросов. API-ключи Bybit, CMC и Coinbase не нужны и кодом не читаются.

## Запуск

BOT_TOKEN обязателен, ALLOWED_USER_ID необязателен (0 — доступ всем). `.env` автоматически не читается. Один процесс на токен и хранилище. Webhook автоматически не удаляется.

```sh
git pull --ff-only
python3 bot.py
```

После обновления отправьте НОВЫЙ /widget. HTML старых сообщений не заменяется; старый shared ID не переиспользуется при миграции USD → USDT. Старые виджеты могут остаться с прежним снимком. Переменная CMC_API_KEY не используется, её можно удалить в Amvera. Деплой вручную здесь не выполнялся.

## Котировки

Фиксированный порядок: BTC, ETH, BNB, XRP, SUI / SOL, TRX, HYPE, ZEC, DOGE. Запрашиваются только эти десять пар SYMBOLUSDT, отдельными GET /v5/market/tickers?category=spot&symbol=...; максимум три HTTP одновременно. Весь рынок не загружается. Только lastPrice и price24hPcnt × 100, не фьючерсы, не USD/indexPrice. Цены и 24h-изменения относятся к Bybit Spot и USDT, а не агрегированному рынку CMC.

Кэш каждой пары 10 с, общий для всех пользователей. Защита от одновременных повторных загрузок, максимум 60 попыток Bybit за скользящие 60 с на процесс, включая неудачные. При 429/retCode ограничения — общая пауза с учётом Retry-After; при HTTP 403 — минимум 600 с. Ошибки пары имеют backoff до 900 с. Во время паузы HTTP не вызывается и повторные предупреждения не пишутся; логируется фактическая ошибка и восстановление. Публичный API может ограничиваться по IP/региону — отсутствие ключа не гарантирует доступность.

Нет фонового сбора: только команда или refresh видимого оригинального виджета в ЛС. JS обращается к боту каждые 10 с; цены запрашиваются только если устарел кэш и нет паузы/лимита. Это целевой интервал, не гарантия: сеть и длительность обработки могут увеличить задержку. Листание локальное. В отсутствие зрителей и команд Bybit/Coinbase не опрашиваются, уже начатая работа может завершиться.

Частичная ошибка не уничтожает другие котировки. Для проблемной пары сохраняются прежняя цена BYBIT и её время; если данных ещё не было — «нет данных», а не ноль и не подмена другим рынком. Каждая строка содержит реальное время успешного получения этой пары. Нижнее время — старейшая из доступных котировок, не время последней попытки. Лампочка декоративная: зелёный–чёрный всегда, не индикатор свежести.

## USD/RUB

Coinbase GET /v2/exchange-rates?currency=USD, поле rates.RUB. Отдельный кэш 60 с, отдельные паузы и отдельное время получения. Это справочный курс Coinbase, не ЦБ/банк и не курс USDT/RUB. Цена крипты в USDT не пересчитывается через USD/RUB.

## Постоянные данные

Все изменяемые файлы в /data: widget_stats.sqlite3 и служебные файлы SQLite, runtime.json и runtime.json.tmp, резервные копии миграций. В исходники/токены ничего не записывается. Хранилище должно быть доступно для записи; тесты используют временные каталоги.

Runtime версии 7 помечен quote_source=bybit_spot_usdt. Из прежних runtime восстанавливается только валидный USD/RUB, НЕ криптоцены в USD. Уже сохранённые Bybit-цены восстанавливаются по каждой паре и её настоящему времени, с заполнением RAM-кэша. Паузы/скользящий limiter после рестарта сбрасываются. Утраченный до деплоя runtime не восстановить. Локальный legacy runtime читается только при отсутствии /data/runtime.json; запись всегда в /data.

SQLite-журнал /widget, его четыре поля, append-only триггеры и автоматическая миграция с backup не меняются. Не удаляйте БД. Не запускайте старый код с четырёхпольной схемой при ожидании восьми полей. Дедупликация не гарантирует exactly-once отправку сообщений.

Админская панель /statistic, индивидуальная /notification по МСК, исключение админов и 30-секундная проверка расписания сохраняются; подробности в ADMIN.md. Запросы статистики к ценовым API не обращаются.

## Проверки

```sh
python3 -m unittest -v
```

Старые CMC-тесты заменены 16 тестами нового провайдера; они выполнены успешно: десять точных пар и порядок, USDT/24h, кэш и конкурентный singleflight, частичные ошибки и время, отсутствие пары/NaN/неверный символ, тихий cooldown, общий лимит, retCode, независимый FX, восстановление и запрет подмены USD на USDT, JSON до 1024 байт. HTML после zlib-9 — 1937 байт. Остальные тесты этой доработкой не менялись и повторно здесь не запускались.

Живые запросы Bybit (включая BTCUSDT/HYPEUSDT/ZECUSDT) из инструмента не прошли. Покрытие всего набора и доступность из Amvera пока не подтверждены. Визуальный рендер/сквозной сценарий Telegram не проверялся. При недоступной паре интерфейс это покажет, не будет скрытой замены другой биржей/фьючерсом.
