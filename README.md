# CryptunaPriceWidget

Python 3.10+. Две страницы по пять монет. SUI закреплена пятой строкой первой страницы. Остальные девять — первые по cmc_rank без дубликата SUI. Если SUI вне топ-10, десятая монета заменяется на SUI. Номера рейтинга настоящие.

## Запуск на macOS / zsh

Остановите старый бот Ctrl+C. В папке репозитория:

```zsh
git pull --ff-only
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
read -r -s 'BOT_TOKEN?Вставь токен бота: '; echo
export BOT_TOKEN
python bot.py
```

Если BOT_TOKEN уже задан, повторно вводить не нужно. Не публикуйте токен. Необязательно задайте ALLOWED_USER_ID; иначе бот доступен любому пользователю в ЛС. `.env` автоматически не читается. Запускайте один процесс на токен и каталог. Существующий webhook программа не удаляет.

Отправьте новый `/widget` или `/prices`. Старые сообщения не меняют HTML и подпись. Новые сообщения отправляются вообще без caption. В неподдерживаемом клиенте не будет текстовой альтернативы. Новый макет прозрачен: фон пузыря рисует Telegram. Нижняя зона учитывает время сообщения. Кит — упрощённый SVG по мотивам референса, с плавным покачиванием. Монеты неподвижны. При reduced motion анимации отключены.

## Данные

Рейтинг и цены в USD: официальный публичный CMC API, `/public-api/v3/cryptocurrency/listings/latest` и `/public-api/v3/cryptocurrency/quotes/latest`. Опрос с целевым периодом 10 с, но CMC обновляет listings примерно раз в 15 с, quotes раз в 15–25 с; сеть и клиентский polling добавляют задержку. Источник не подменяется Coinbase при ошибках. USD/RUB: справочный Coinbase `/v2/exchange-rates?currency=USD`, не банковский курс и не ЦБ; период формирования исходного курса не гарантирован.

Логотипы берутся из CMC metadata `/public-api/v2/cryptocurrency/info`, скачиваются ботом с s2.coinmarketcap.com и встраиваются как PNG data URLs. Pillow уменьшает размер и палитру до прохождения лимита Telegram. Логотипы могут быть пиксельными. Бот проверяет 32768 байт HTML и 4096 байт после zlib-9; если не помещается или CDN недоступен, отправка завершается ошибкой, буквы вместо логотипов не подставляются.

## Состав и сохранение

HTML, логотипы и состав конкретного shared widget фиксируются при отправке. Фоновый поток получает новый рейтинг, но уже отправленный виджет сохраняет свой набор и порядок монет; обновляет их цены и номера рейтинга. Чтобы применить новый состав/порядок топа, отправьте `/widget`: при изменении списка создаётся новый shared widget. После этого старый поток больше не обновляется. Этот бот поддерживает один активный shared widget, а не реестр всех исторических версий.

`runtime.json` сохраняет активный ID, список и последние котировки без токена; файл исключён из Git. Перезапуск восстанавливает значения. При сбое цены остаются на экране, предупреждений о задержке нет. Сохраняется время последнего получения криптоцен; индикатор становится нейтральным через 45 с. Время получения не равно времени сделки. При отсутствии первого значения показывается прочерк. Бот должен оставаться запущенным. Offset обновлений в памяти: exactly-once не обещается.

## Проверка

```sh
python -m unittest -v
```

Шесть mock-тестов: SUI внутри/вне топа, отсутствие дубликатов, формат V3, лимит состояния, ошибки API и чисел. Дополнительно при подготовке проверена сборка HTML с десятью тестовыми изображениями: 3534 байта после zlib-9. Это не измерение реальных логотипов; их размер проверяется при отправке. Живые CMC endpoints и новый виджет в Telegram end-to-end при подготовке не проверены.
