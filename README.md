# CryptunaPriceWidget — Binance / USDT

Python 3.10+, только стандартная библиотека. Все цены берутся из публичных API без ключей. Ключи CMC, Bybit, Binance и Coinbase не нужны и кодом не читаются; `CMC_API_KEY` в Amvera можно удалить.

## Запуск

`BOT_TOKEN` обязателен, `ALLOWED_USER_ID` необязателен (0 — доступ всем). Один процесс на токен и хранилище. Webhook автоматически не удаляется.

```sh
git pull --ff-only
python3 bot.py
```

После обновления отправьте НОВЫЙ `/widget`: HTML старых сообщений не заменяется. Прежние сохранённые цены Bybit/CMC при запуске не восстанавливаются, чтобы не смешивать источники.

## Котировки

Три страницы виджета (по 5 строк):
1. и 2. криптовалюты: BTC, ETH, BNB, XRP, SUI / SOL, TRX, HYPE, GRAM, DOGE. Источник — Binance Spot, пары `SYMBOLUSDT`. Один запрос `GET https://api.binance.com/api/v3/ticker/24hr?symbols=[...]` на все десять пар (вес 2 из 6000 в минуту на IP).
3. металлы: золото `XAUUSDT`, палладий `XPDUSDT`, серебро `XAGUSDT`. Источник — Binance Futures (бессрочные контракты TradFi), `GET https://fapi.binance.com/fapi/v1/ticker/24hr?symbol=...`, цена в USDT за тройскую унцию. Это фьючерсы, а не спотовая цена металла.

Используются только поля `lastPrice` и `priceChangePercent` (уже в процентах). USD/RUB — Coinbase `GET /v2/exchange-rates?currency=USD`, поле `rates.RUB`, отдельный кэш 60 секунд.

Кэш каждой пары 10 секунд, общий для всех пользователей. Запросы идут только по команде `/widget` или по обновлению видимого виджета в личном чате; без зрителей источники не опрашиваются. Не больше 60 попыток в скользящую минуту. При `429`/`418` общая пауза с учётом `Retry-After`, при `403`/`451` — минимум 600 секунд. Ошибки пары имеют backoff до 900 секунд, повторные предупреждения во время паузы не пишутся.

Если Binance отвечает ошибкой `400` на пакетный запрос (например, пару убрали), код один раз опрашивает пары по отдельности и изолирует проблемную. Для проблемной монеты остаётся прежняя цена и её время, а если данных не было — «Нет данных». Подмены другой биржей или рынком нет.

Внизу виджета одно время: «Получено от: ЧЧ:ММ:СС» — самая старая из доступных котировок. У каждой строки есть своё время получения. Лампочка декоративная и не показывает свежесть данных.

Binance может ограничивать доступ по региону/IP, поэтому после деплоя проверьте логи (`Binance Spot bulk request`, `Binance Futures/...`).

## Постоянные данные

Все изменяемые файлы лежат в `/data`: `widget_stats.sqlite3`, `runtime.json`, резервные копии миграций. Токен нигде не сохраняется. `runtime.json` версии 8 помечен `quote_source=binance_spot_futures_usdt`.

Журнал `/widget`, админская панель `/statistic` (с карточкой и списком уведомлений), `/notification` для админов и пользовательские `/notificationsettings` описаны в `ADMIN.md` и `NOTIFICATIONS.md`.

## Проверки

```sh
python3 -m unittest -v
```

Тесты котировок используют подставные ответы API. Живые запросы к Binance из среды разработки не выполнялись; доступность из Amvera и наличие всех пар нужно проверить после деплоя. Документация: https://developers.binance.com/docs/binance-spot-api-docs/rest-api/market-data-endpoints , https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates , https://core.telegram.org/bots/widgets.md .
