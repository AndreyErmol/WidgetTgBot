# CryptunaPriceWidget

Python 3.10+, стандартная библиотека. Две страницы по пять монет. USDT и USDC исключены. SUI пятая на первой странице, без надписи «закреплена». Остальные девять — первые подходящие по cmc_rank. Набор и порядок меняются через public_data. Значки буквенные; кита, внешних логотипов и caption нет.

## Обновление (macOS / zsh)

Остановите процесс Ctrl+C. В папке репозитория:

```zsh
git pull --ff-only
python3 bot.py
```

Pillow больше не нужен. Если BOT_TOKEN не задан:

```zsh
read -r -s 'BOT_TOKEN?Вставь токен бота: '; echo
export BOT_TOKEN
python3 bot.py
```

После запуска отправьте новый `/widget` или `/prices`: HTML старых сообщений не меняется. Токен не публикуйте. ALLOWED_USER_ID необязателен; без него бот доступен всем в ЛС. `.env` автоматически не читается. Только один процесс на токен/каталог; webhook самостоятельно не удаляется.

## Кэш и ограничения запросов

Один фоновый сборщик получает первые 100 CMC listings одним пакетным запросом для всех пользователей. Если SUI вне них, добавляется quotes/latest по slug. TTL 10 с, single-flight lock предотвращает конкурентные повторные загрузки. Команды пользователей не обращаются к CMC вообще. У Coinbase USD/RUB отдельный кэш 60 с. Целевой цикл публикации 10 с; это не гарантия свежей котировки и точной задержки на экране.

HTTP 429 учитывает Retry-After (секунды/HTTP-дата); Telegram — также parameters.retry_after. CMC и Coinbase имеют отдельные cooldown, экспоненциальный backoff и jitter, при 429 минимум 60 с или больше по указанию сервера. При сетевых ошибках используются последние цены без обновления времени их получения. Снижение запросов не гарантирует исчезновение 429 при общем IP или нескольких процессах. В разных процессах кэш не общий. Логи указывают источник ошибки. TLS-проверка не отключается; кэш не исправляет обрывы TLS и handshake timeouts.

## Отображение

Проценты форматируются отдельно: -2.19 → -2,19%, без умножения на 100 и пробелов в дробной части. Два знака после запятой, без искусственного ограничения величины. Цены группируют только целую часть, для значений меньше 0.01 — шесть знаков.

Лампочка постоянно пульсирует зелёный → #000000 → зелёный независимо от свежести данных; она декоративная, не индикатор доступности источника. Клиент Telegram может самостоятельно ограничить анимации. При сбоях сохраняются цены и время получения; надписей «задержка» нет. До первого успешного ответа — прочерки. USD/RUB отдельно внизу: справочный Coinbase, не ЦБ/банк, обновление самого источника не гарантировано. Верхний заголовок — CryptunaPriceWidget. Фон рисует Telegram.

runtime.json хранит ID shared widget и снимок без токена, исключён из Git. Перезапуск восстанавливает значения. Старый макет при миграции с v3 не переиспользуется. Если после удаления стейблкоинов не хватает сохранённых монет, ждём свежий снимок. Offset обновлений только в памяти, exactly-once не обещается.

## Тесты

```sh
python3 -m unittest -v
```

9 mock-тестов логики прошли при подготовке: фильтры/SUI, форматирование, лимит состояния, конкурентный single-flight, cooldown и сохранение timestamp при 429, 20 отправок без запросов в CMC. Живой end-to-end тест Telegram/CMC и воспроизведение пользовательского 429 не выполнялись.
